This is a page for documenting the BIMTester functionality from [ifcOpenShell](/ifcopenshell/) as implemented in [Bonsai](/bonsai/)

BIMTester is for auditing IFC files against a variety of [tests](/categories/bimtester/). It has the following features:
- Integration with [Bonsai](/bonsai/) and FreeCAD as well as Standalone GUI.
- Support for unit tests known as [MicroMVDs](/micromvds-for-exchange-requirements/) written as .feature files
- Support (beta) for [IDS - Information Delivery Specification](/ids-information-delivery-specification/) files
- Generation of reports
- Auditing parts of a file
- Support for full [Model View Definitions (MVD)](/mvd-model-view-definitions/)
- Uses existing unit testing standards and spits out JUnit XML
