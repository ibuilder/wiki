dotbim is an open-source, accessible, simple, minimalist file format for BIM. Built to be easy to read and write. Created by BIM developers for BIM developers.

Thanks to the open-source community, there are:
- Libraries for C#, Python and Typescript
- Importers and exporters for Archicad, Grasshopper, SketchUp, Blender, Online 3d Viewer
- Converters to and from IFC and DXF
- Multiple example files
