## Introduction
This project serves as an example Step by Step project for a full Architectural development, a basic step by step project playlist can be found here:

https://youtube.com/playlist?list=PLMDcOjMJYxUPl3l8baXK8F__KtbuOY7VB

This is broken into 6 videos covering:

- Part 1 - Modelling

- Part 2 - 2d drafting

- Part 3 - 2d Section & Elevation

- Part 4 - 2d Detail

- Part 5 - Page Layout

- Part 6 - Line weights & more

The rest of this article is a more comprehensive project hooked to stages of Architectural work in a project. 
This aims to be a simple but comprehensive step-by-step project with Bonsai.
The first draft of this project is based on the Stages of Work for an Architect, it will be adjusted and updated incrementally to follow a more internationally agreed set of work stages.

These tools need to be installed to complete this project: 			

Blender

Bonsai	
			
BlenderGIS	(Optional)	
		
Inkscape	
		
LibreOffice
