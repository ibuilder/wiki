"Tekla Structures is a building information modeling software able to model structures that incorporate different kinds of building materials, including steel, concrete, timber and glass. Tekla allows structural drafters and engineers to design a building structure and its components using 3D modeling, generate 2D drawings and access building information." ([Wikipedia](https://en.wikipedia.org/wiki/Tekla_Structures))

Tekla Structures is best known for being the leading software for steel construction in AEC.

Tekla and Solibri were the original developers of the [BIM Collaboration Format (BCF)](/bcf-bim-collaboration-format/)

Tekla Structures is certified for IFC 2x3 import and export and certified for IFC 4 Structural Reference Exchange export, but not yet import (2020-12-22)<https://www.buildingsmart.org/compliance/software-certification/certified-software/>
