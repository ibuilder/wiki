## Description
ArchiCAD is an architectural, BIM capable design software developed by [Graphisoft](https://graphisoft.com/) and available on both Mac and Windows systems.

For a more comprehensive description see the product documentation or their [wikipedia article](https://en.wikipedia.org/wiki/ArchiCAD)

## Support for [OpenBIM](/openbim/)
ArchiCAD has traditionally been an advocate of interoperability and a proponent of the [OpenBIM](/openbim/) concept when it aligns with their commercial interests. 

**BCF**

ArchiCAD [supports](https://help.graphisoft.com/AC/23/int/_AC23_Help/080_Collaboration/080_Collaboration-73.htm) in product import of [BIM Collaboration Format (BCF)](/bcf-bim-collaboration-format/) files.

**IFC**

They have typically been quick to achieve [BuildingSMART International](/buildingsmart-international/) certification for [Industry Foundation Classes (IFC)](/ifc-industry-foundation-classes/) import and export. ArchiCAD have developed custom export tools for exporting from other software to IFC format better suited to ArchiCAD import. buildingSMART Denmark have written an [IFC Export Guide for Revit and ArchiCAD](https://anvisninger.molio.dk/Gratis-vaerktojer/buildingSMART/IFC_Export_Guide_EN)
