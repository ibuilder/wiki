"libdxfrw is a free C++ library to read and write [Drawing Exchange Format (DXF)](/drawing-exchange-format-dxf/) files in both formats, ascii and binary form. Also can read [Drawing (DWG)](/drawing-dwg/) files from R14 to the last V2015."

libDWXrw had two commits in 2020.

It is the default DXF/DWG library for [LibreCAD](/librecad/)
