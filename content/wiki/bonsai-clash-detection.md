## Description
Bonsai implements Clash Detection between IFC files.

## External Resources
**Bonsai - Clash Sets** shows the IFCClash tool from [IfcOpenShell](/ifcopenshell/) as implemented in [Bonsai](/bonsai/)
<div style="float: right; margin: 30px;">{{< youtube "https://www.youtube.com/watch?v=99i4leHzUC4" >}}</div>
  

*Cómo detectar colisiones con Bonsai* shows the process of importing two IFC files generated from [ArchiCAD](/archicad/) into Bonsai to execute a Clash Detection. After importing each IFC file into Blender via Bonsai, the Clash Detection tool generates a JSON file with all information on the clashing IFC elements. Afterwards, the JSON file is used to identify and select these elements. Note that both Blend files must be Linked.
