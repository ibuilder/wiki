Ladybug Tools is a collection of free computer applications that support environmental design and education connecting 3D Computer-Aided Design (CAD) interfaces to a host of validated simulation engines. Although Ladybug Tools do ship platform agnostic libraries, it is originally designed as grasshopper nodes for the proprietary [Rhinoceros 3D](/rhinoceros-3d/) software and now also has integration with [Blender](/blender/).

The Ladybug tools provide a "web of interoperability" with many tool, including libre software packages:
- [Radiance](/radiance/)
- [OpenStudio](/openstudio/)
- [EnergyPlus](/energyplus/)
- [OpenFOAM](/openfoam/)
- [URBANopt](/URBANopt/)

The Ladybug tools also provide interoperability with proprietary software such as [Rhino](/rhinoceros-3d/) and [Autodesk Revit](/autodesk-revit/) ([under development](https://archi-lab.net/honeybee-meets-revit/))
