"The (BCF-Plugin-FreeCAD) plugin is aimed at the free CAD software [FreeCAD](/freecad/) and wants to integrate support for the [BCF](/bcf-bim-collaboration-format/) standard into it. Therefore, the plugin is developed as standalone application that can be started from inside [FreeCAD](/freecad/) in one of two modes: GUI and non-GUI mode."

Links:
[Wiki](https://github.com/podestplatz/BCF-Plugin-FreeCAD/wiki), [FreeCAD development discussion](https://forum.freecadweb.org/viewtopic.php?f=8&t=35465)

This project is being replaced by a BCF python library as part of the [IfcOpenShell](/ifcopenshell/) project.
