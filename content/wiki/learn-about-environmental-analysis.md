Once you have some 3D geometry you can begin to investigate how it will perform in its environment.

There is a selection of tools in the [Analysis and Simulation](/aec-free-software-directory/#analysis-and-simulation) section of the main software list.

Creating meaningful building energy models (BEM) is described on the [Energy Modeling](/building-energy-modeling-bem/) page.

A powerful and mature tool-set which can run many types of analysis is [Ladybug Tools](/ladybug-tools/) which has connections to both proprietary and free/libre software projects. Read more about that on the [Ladybug Tools](/ladybug-tools/) page.

[TopologicEnergy](/TopologicEnergy/) can also run basic energy analysis in Blender using [topologic](/topologic/), [OpenStudio](/openstudio/), and [EnergyPlus](/energyplus/). It is 100% free and open-source.
