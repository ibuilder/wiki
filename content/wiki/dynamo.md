"Dynamo is a visual programming tool that aims to be accessible to both non-programmers and programmers alike. It gives users the ability to visually script behavior, define custom pieces of logic, and script using various textual programming languages." [github readme](https://github.com/DynamoDS/Dynamo#readme)

Originally developed by [Ian Keough](https://github.com/ikeough) as libre / opensource primarily for integration into [Autodesk Revit](/autodesk-revit/) in ways similar to [Sverchok](/sverchok/) for [FreeCAD](/freecad/) & [Blender](/blender/), Blender geometry nodes, or [Grasshopper](https://en.wikipedia.org/wiki/Grasshopper_3D) for [Rhinoceros 3D](/rhinoceros-3d/).

A lot of the [node packages licensed as open source / libre software](https://chuongmep.github.io/Awesome-Dynamo/DynamoOpenSource/dynopensource.html).
