## Software Libraries for working with IFC
- [IFC.js](/ifc-js/) is a javascript library for handling IFC data
- [Xeokit](/xeokit/) is a Web Programming Toolkit for AEC Graphics, including IFC
- [IfcOpenShell](/ifcopenshell/) is a collection of C++ libraries with Python bindings and integration with [FreeCAD](/freecad/) and [Blender](/blender/)
- [IFC-dotnet](https://github.com/ikeough/IFC-dotnet) is a C# IFC library for .NET Core under an MIT license (innactive for several years)
- [XbimEssentials](https://github.com/xBimTeam/XbimEssentials) is a .NET library to work with data in the IFC format. This is the core component of the [Xbim Toolkit](https://docs.xbim.net/) and under a CPPL license
- [GeometryGymIFC](https://github.com/GeometryGym/GeometryGymIFC) C# classes to generate and parse OpenBIM IFC (Industry Foundation Class) files. (GeometryGym is a whole suite of tools and plugins)

There is a [discussion on the forum](https://community.osarch.org/discussion/1089/thoughts-on-using-ifc-js-and-ifcopenshell-in-combination) comparing some of these libraries. The IfcOpenShell project has done a study to see exactly [how much each open source technology currently is capable of scaling](https://github.com/IfcOpenShell/IfcOpenShell/issues/2224).
