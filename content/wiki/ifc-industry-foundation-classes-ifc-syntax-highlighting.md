As [IFC](https://technical.buildingsmart.org/standards/ifc/ifc-formats/) is usually saved in full text it is handy to have a syntax highlighting in it : {{< wiki-image src="/media/ifc-spf-syntax-highlighting-example.png" alt="IFC-SPF syntax highlighting example" mode="thumb" caption="IFC-SPF syntax highlighting example" >}}

| Editor | Link | Syntax |
| --- | --- | --- |
| geany | [By yorik](https://community.osarch.org/discussion/comment/1361/#Comment_1361) | IFC-SPF |
| Notepad++ | [IFC Language Styler](https://github.com/JulesBuh/ifcParser/blob/master/NotePad_Styles/NotePad%2B%2BIFCLanguageStyler.xml) | IFC-SPF |
| Vim | [By brunopostle](https://community.osarch.org/discussion/29/ifc-vim-syntax-highlighting)  
or <code>:set syntax=stp</code> (For STEP) | IFC-SPF, STEP |
| Visual Studio Code | [ifc-syntax extension](https://github.com/AlanRynne/ifc-syntax) | IFC-SPF, EXPRESS |
