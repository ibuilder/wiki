This is planned to be the starting page for a series on starting to code for free/libre opensource (FOSS) software projects.

Feel free to ask in the [discussion forum](https://community.osarch.org) if you're ready to start learning - we can then start developing learning material together.

Start by visiting the [Start coding](/Category:Start_coding/) to see what pages we already have. There are also lots of resources on the internet. Here are some directly related to projects on our [AEC Free Software directory](/aec-free-software-directory/):

- [Sverchok](/sverchok/) is a node based programming environment for several uses. See links on it's page and ask for help in our [discussion forum](https://community.osarch.org).
- [Topologic](/topologic/) is a node based programming environment for several uses. See links on it's page and ask for help in our [discussion forum](https://community.osarch.org)
- [FreeCAD](/freecad/) has a page for their [Python scripting tutorial](https://wiki.freecadweb.org/Python_scripting_tutorial)
- [Blender](/blender/) can be scripted with Python. Here's a good [Python crash course video for Blender](https://www.youtube.com/watch?v=XqX5wh4YeRw).
- [Bonsai](/bonsai/) can be scripted with Python. See for example: [Bonsai code examples](/bonsai-code-examples/)
- [IfcOpenShell](/ifcopenshell/) can easily be used to interrogate [IFC](/ifc-industry-foundation-classes/) data, see the [IfcOpenShell code examples](/ifcopenshell-code-examples/)

There are also [Free software extensions to proprietary software](/free-software-extensions-to-proprietary-software/) which can be leveraged by learning to code
- [pyRevit](/pyrevit/) is a Python based rapid development framework for adding functionality to the [Proprietary software](/categories/proprietary-software/) [Autodesk Revit](/autodesk-revit/): [Create your first command](https://www.notion.so/Create-Your-First-Command-2509b43e28bd498fba937f5c1be7f485)
- [Dynamo](/dynamo/) is a node based programming environment for the [Proprietary software](/categories/proprietary-software/) [Autodesk Revit](/autodesk-revit/). [Learn Dynamo BIM](https://dynamobim.org/learn/). New nodes can be written in Python and you can learn from the code many available [node packages](https://dynamopackages.com/).

That's a few things to get started with.
