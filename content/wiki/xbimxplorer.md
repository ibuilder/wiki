[xBIM Xplorer](http://docs.xbim.net/downloads/xbimxplorer.html)

XbimXplorer is a Windows-only viewer capable of loading [IFC](/Industry_Foundation_Class/)2x3 and [IFC](/Industry_Foundation_Class/)4 models, and has a modular infrastructure to load plugins. Features include IFC Schema Validation, Querying syntax for data extraction, IFC stripping and Federated model loading (beta, with known issues). It is a demonstration project showcasing the [xbim toolkit](https://docs.xbim.net/index.html).

Basic Navigation
- Rotate : right mouse click
- Zoom : mouse scroll
- Move : Middle mouse button
- Cut : Shift left click on an object
- Measure : Alt left click
- Focale : Alt right click
