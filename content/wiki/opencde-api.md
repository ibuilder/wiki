An open common data environment ([CDE](https://www.designingbuildings.co.uk/wiki/Common_data_environment_CDE)) application programming interface ([API](https://en.wikipedia.org/wiki/Application_programming_interface)) would make it possible to create end user software that can interact with multiple CDE from a common user interface. This woule avoid the pain of learning new methods for each CDE on where settings are stored, how permissions are managed, how revisions are managed and so on.

> The 'open connected data environment APIs' project aims to improve interoperability within the AEC software ecosystem through closely-knit, domain-specific APIs
https://technical.buildingsmart.org/projects/opencde-api/
