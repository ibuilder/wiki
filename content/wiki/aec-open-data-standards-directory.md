Open data standards, often represented as file formats allow AEC tools to exchange datasets in a transparent and reliable manner. These could be file formats like [.ifc](/ifc-industry-foundation-classes/) or [.svg](/scalable-vector-graphics-svg/) or they could be database formats or more generically data schemas that can be used in many ways (IFC can be both)

This page is a directory of open file formats and data standards. For a comparison of some popular file formats see [File format comparison](/file-format-comparison/)
