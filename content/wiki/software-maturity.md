[Software pages](/categories/software/) in the wiki should include an [InfoBox](/Template:Infobox_software/) with information on an applications maturity. The suggested maturity levels are as follows:

- [Mature](/Category:Mature/): Software ready for production use. Stable, feature rich and dependable

- [Functional](/Category:Functional/): Software that works and is unlikely to ruin your workflow. Can be a non-critical part of a production workflow

- [Promising](/Category:Promising/): Software on the way but lacking key functionality or stability. Can supplement a production workflow for testing purposes and gathering feedback for the developers

- [Immature](/Category:Immature/): Promising software under active development that needs feedback and testing

- [Concept](/Category:Concept/): A proof of concept ready to see more development

- [Unknown](/Category:Unknown/): Maturity status unknown by editor. Please update if You have knowledge about it.
