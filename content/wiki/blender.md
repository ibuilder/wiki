Blender is libre and open-source 3D computer graphics software used for creating animated films, visual effects, art, 3D printed models, motion graphics, interactive 3D applications, virtual reality, and computer games. Blender has a huge set of features for many uses and can be a powerful tool for architectural visualizations and animation as well as model authoring. For model authoring it is a really good idea to look at the [add-ons to Blender for construction modelling](/categories/blender-add-on/)
