GNU LibreDWG is a free C library to handle DWG files. It also has python binding and much more.

Some newer versions (v0.19_pre) of [FreeCAD](/freecad/) use LibreDWG by default.

- License: GPLv3-or-later
- Website: https://www.gnu.org/software/libredwg/
- Donations: [Donation Directory#LibreDWG](/donation-directory/#libredwg)
